# SQEMM

SQEMM is an open source LIM EMS 4.0 driver targeting several add on boards and chipsets. 

The goal is to provide full fledged "max" and "min" drivers for various chipsets. The max driver aims to be be fully LIM EMS 4.0 compliant while the min driver is optimized for speed and size and works as a "single application driver", allowing the fastest possible EMS support for software like games.

The current version is 0.8. 

SQEMM passes various EMS 4.0 test suites but needs more real world testing. I hope you give it a try and provide feedback.
